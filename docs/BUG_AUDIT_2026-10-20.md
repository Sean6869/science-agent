# 平台 BUG 审查与根因修复记录

范围：登录与会话、教师/管理员管理、三课探究、分组与组内同步、AI 反馈与次数、记录清理与导出、前后测、语音及部署文件。

## 本轮修复

| 问题与触发条件 | 根因与修复 | 回归验证 |
| --- | --- | --- |
| 批准清空后，教师删除档案，新消息可能不再出现 | SQLite 隐式行号在删除后可复用。增加持久递增会话序号，沿用旧清空边界并在迁移时校准序号下限 | 实际数据库测试覆盖清空、删除、旧结构迁移与重启后的新消息显示 |
| 角色分工更新或清空申请遇到冲突时，页面误刷新 | 前端将全部 HTTP 409 当成账号切换。改为只对带 `SESSION_CHANGED` 的冲突刷新，角色冲突重新读取分工 | 会话响应测试与角色版本校验 |
| 快速切课后旧请求锁住新课程或把旧提示写到新课程 | 请求中状态未按课程隔离。按课程状态区分待处理反馈，对知识答疑、自评及科学推理回调检查当前状态，切课停止旧录音并关闭旧教练 | 隔离前端测试覆盖 A→B→A、旧请求失败、新课程仍在请求等时序 |
| 连续点选环节后被旧请求或轮询拉回 | 环节保存并发发送，轮询没有识别更新后的本地选择。保存请求按点击顺序串行，忽略新选择之前启动的读取 | 同步控制器测试覆盖写入顺序、旧读取丢弃、失败后恢复及组员更新 |
| 自评少报剩余次数，第四次提交使后台计数继续增加 | 内容次数用于下一次提交，但自评也沿用该值；次数耗尽的请求仍进入正式记录。自评使用当前次数，超限请求在入库前拦截 | 本地 HTTP 测试验证三次提交、反复超限及自评剩余次数 |
| 第六环节未结合第五环节的固定结论 | 组内上下文只读取在线模型来源，遗漏第五环节的规则判分。读取成功的模型与规则内容产出 | 组内记录测试验证第六环节包含第五环节最新结论 |
| 教师操作后跳回看板、迟到的响应污染工具栏或筛选结果 | 账号保存/导入回调默认打开看板，部分异步面板未检查是否仍显示，筛选未区分请求先后。保留学生账号页，对失效面板及过期筛选响应停止更新 | 隔离前端测试覆盖看板迟到刷新、学生筛选倒序返回 |

## 已复核的需求

- 第一节课第五环节包含任务单四条实验结论，新增两条按空格逐项判错。
- 学生清空由教师/管理员在进度看板审核；批准前与拒绝后保留原记录，批准后保留服务器 AI 对话和导出能力。
- 教师学生账号页的“清除学习记录”仍为服务器删除：AI 对话被删除后无法导出。该语义已在部署说明中写明。
- 分组自动策略仍为高低优先、高高其次、低低最后；现有权限、分组、测验、语音与导出回归测试继续覆盖。

## 验证与限制

- 全量自动回归使用隔离数据库及本地 HTTP 服务；前端时序使用 DOM 替身进行行为测试。119 项测试通过，语法检查通过。
- 浏览器工具在重新初始化后仍返回 `Local browser use is disabled in Work settings`，未完成真实浏览器的视觉、视口尺寸与滚动验收。未用其他方式绕过该访问限制。
- 在线 AI 与语音的协议、错误恢复和备用回复在测试中覆盖，测试通过不代表生产环境上游服务持续可用。
- 未对生产学生数据执行清空、删除或重置；数据库升级流程已在测试副本验证。
